## Statusvokabulär

- `untriaged` — spår identifierat, inget arbete påbörjat.
- `grilling` — `/grill-with-docs` pågår.
- `designed` — ADR/mall skriven och godkänd.
- `on-runlist` — PRD publicerad i körlistan.
- `done` — implementerat och commitat.
- `deferred` — medvetet uppskjutet.
